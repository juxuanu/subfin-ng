Subfin

Subsonic apps connect to your Jellyfin address with the path , signing in with a Jellyfin username and that user's OpenSubsonic password, generated below. The OpenSubsonic password works with token login, the way Navidrome prefers apps to sign in, and with plain password login. Apps that offer plain password (“legacy”) login can use the Jellyfin password instead; token login can't use it, because Jellyfin only stores a hash of it.

OpenSubsonic passwords

A password is shown once, when it's generated. Regenerating or removing it signs out the apps using it.
